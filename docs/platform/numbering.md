# 编号规则中心

入口为「系统管理 → 编号规则」，用于统一管理业务编号的格式、流水设置、发布版本和生成记录。页面包含「编号规则」与「生成记录」两个页签。

## 规则与使用方式

| 配置 | 作用 | 操作位置 |
| --- | --- | --- |
| 编号规则 | 定义模板、起始值、步长、补零位数、计数范围、时区和重置周期 | 编号规则列表的新增 / 编辑 |
| 适用业务类型 | 限定规则允许的参数、长度、字符和唯一性要求，例如流程实例或支付订单 | 规则创建时选择，创建后固定 |
| 默认规则 | 指定某种业务未单独选择规则时采用的发布版本 | 编号规则列表的「默认规则」 |
| 业务专用规则 | 为具体业务对象选择规则和版本，并配置表单字段来源 | 业务自身设置，例如流程设计器的「更多设置」 |
| 使用位置 | 查看默认配置和已发布 / 禁用流程实际固定的规则版本 | 规则详情，只读展示 |

编号中心不要求用户重复创建“接入记录”。规则定义格式，业务自身决定使用哪条规则；系统在业务发布或创建事务中处理实际引用。

## 创建与发布规则

1. 新增规则，填写规则名称、编码和适用业务类型。
2. 使用分段配置或高级模板定义编号。模板片段按钮展示中文含义和示例；高级模板支持日期、流水、系统身份变量及多个表单字段。
3. 在右侧查看实时示例。预览不占用正式流水；桌面侧栏的左侧表单与右侧预览独立滚动，窄屏恢复单列。
4. 保存草稿后发布版本，供默认配置或具体业务选择。

发布版本不可修改，发布新版不会自动切换现有默认配置或业务引用，也不会清空流水。首次发布后，起始值、步长、重置周期、时区和计数范围固定；需要改变序列口径时新建或复制规则。

## 配置默认规则

「默认规则」固定列出已注册业务类型，不提供新增任意业务对象。选择某一业务类型后，只需选择启用的规则及其已发布版本。

租户可为允许自定义的业务设置自己的默认规则；未设置时继承平台默认。已有租户覆盖可以通过「恢复平台默认」移除，平台默认本身通过选择新规则版本替换。支付编号受渠道协议约束，只能由平台管理员在平台视角维护。

修改默认配置影响后续使用默认规则的业务，已生成编号保持不变。已发布流程固定了规则版本，需要在流程设计器中保存并重新发布才会采用新默认。

## 流程使用编号规则

流程设计器「更多设置」可以选择专用规则版本，并配置模板需要的字段来源；不选择专用规则时使用当前业务类型默认。清空专用选择并重新发布，表示恢复采用当前默认。

流程发布时冻结规则版本及字段映射。高级模板中的 `FORM` 字段可以按编码或唯一名称自动匹配，重名字段需要显式选择；具体语义见[表单设计](../workflow/form-design.md)。首次正式提交生成编号，草稿不取号；同一实例退回后重提保留原编号。

## 使用位置与生成记录

规则详情显示默认配置和具体流程的名称、作用域及实际固定版本。流程入口跳转至设计器，专用选择在该业务中修改；详情不直接编辑业务规则关系。

「生成记录」保留正式编号、业务类型和关联单据，可以跳转查看业务。它是编号幂等与防重凭据，业务撤回、作废或删除允许删除的草稿时不回收已分配号码。
